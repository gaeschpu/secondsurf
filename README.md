# secondsurf.ch

Source of the secondsurf website (second-hand surf clothing, Switzerland). The Astro project is in [`website/`](website/README.md); see its README for how to add products, edit texts and deploy.

Structure inspired by jamdrobe.com.au: announcement bar, new drop, shop by category and size, staff picks, and a "Sell" section for stockists (regular resellers) and one-off sellers.
Private material (original photos, invoices, stockist lists) goes into `raw-docs/`, which is git-ignored.
